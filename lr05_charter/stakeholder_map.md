## 3. Матриця RACI (попередня)

Позначення: **R** — виконує; **A** — кінцево відповідає; **C** — консультація; **I** — інформують. У кожному рядку одна кінцева відповідальність A.

| Результат / рішення | Спонсор | PO | PM | BA | Dev | QA | Власник даних / InfoSec |
| --- | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| Статут і бюджет | A | C | R | C | I | I | C |
| Пріоритети MVP | I | A | C | R | C | C | C |
| Правила погодження | I | A | C | R | C | C | C |
| План спринту та ризики | I | C | A | R | R | C | C |
| Інтеграція з розкладом | I | C | C | C | R | C | A |
| Якість і приймальні сценарії | I | A | C | C | R | R | C |
| Дозвіл пілотного запуску | A | R | R | C | C | C | C |

**Примітка:** право InfoSec призупинити небезпечний реліз не замінює повноваження спонсора затверджувати загальний пілот. Конкретна система прав затверджується за політиками закладу.

## 5. Стратегії для непростих ситуацій

- **PO не відповів протягом 5 робочих днів:** PM фіксує нерозв'язане питання та ризик, не додає неузгоджену історію до committed sprint, звертається до спонсора. SLA відповіді — лише пропозиція.
- **Власник розкладу не дає доступу:** зупинити живий сценарій, показати знеособлене демо і запропонувати варіанти sponsor/PO до W6.
- **Погоджувачі сперечаються про права:** BA приносить матрицю конфліктних ситуацій, PO/спонсор погоджує конкретне правило перед реалізацією.
- **Користувачі не приймають інтерфейс:** сформувати backlog поліпшень за результатами 10 контрольних сценаріїв; не маскувати невиконаний KPI.

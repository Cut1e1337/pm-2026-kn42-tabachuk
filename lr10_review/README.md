## Що я забрав із чужого портфеля

Знахідка з моєї рецензії і що з нею роблю: у портфелі Sque1ze кожна роль у `lr16_budget/rate_card.csv` має окреме джерело ставки, звіт DOU саме про цю спеціальність, і відношення до ставки Dev записане в `note`. У мене одне посилання на калькулятор DOU на всі ролі. До захисту я ставлю кожній ролі власне джерело в `lr16_budget/rate_card.csv` і переношу коефіцієнти 1,10 / 0,93 / 1,00 / 0,71 з тексту README в `note`, щоб відповідь на «звідки 402,50» читалась з самого файла.
